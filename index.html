Sets

1st set (warm up): 10-12 reps (50-60% of 1-2 reps max)

2nd set (working set):

  • 4-6 reps (70-90% of 1-2 reps max) for compound exercises
  • 10+ reps for isolation exercises for rear and lateral deltoids, forearms muscles group, and abs

3rd set (drop set):

  • 8+ reps to failure for compound exercises
  • 12+ reps to failure for isolation exercise
